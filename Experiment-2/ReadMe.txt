EXPERIMENT 2: VEHICLE MANAGEMENT SYSTEM USING JAVA OOP

AIM
To develop a Vehicle Management System using Java that demonstrates object oriented programming concepts such as classes, objects, constructors, encapsulation and arrays of objects.

OBJECTIVES
- Understand object oriented programming structure in Java
- Implement constructor overloading including default, parameterized and copy constructors
- Apply encapsulation using private variables with getter and setter methods
- Manage multiple objects using arrays
- Display structured data using formatted output

DESCRIPTION
This program implements a Vehicle Management System using two classes:

1. Vehicle
   Contains vehicle attributes, constructors, getter setter methods, and behaviour methods such as start, drive, stop, mileage calculation and fuel efficiency display.

2. Main
   Creates multiple Vehicle objects using different constructors and stores them in an array called garage. It assigns specifications to each vehicle and prints all vehicle details in a formatted table including calculated efficiency based on fuel type.


FEATURES
- Vehicle class with multiple attributes
- Constructor overloading
- Encapsulation using private variables
- Getter and setter methods
- Arrays of objects
- Formatted table output
- Fuel efficiency calculation based on fuel type

EXPECTED OUTPUT
- Multiple vehicle objects are created
- Vehicle specifications are stored in an array
- Program displays a formatted table showing vehicle details
- Efficiency values are calculated based on fuel type
