EXPERIMENT 1: MENU DRIVEN BASIC CALCULATOR IN JAVA

AIM
To develop a menu driven basic calculator using Java that performs arithmetic operations using classes and methods.

OBJECTIVES
- Understand class based program structure in Java
- Implement arithmetic operations using methods
- Implement menu driven programs using loops and conditionals

DESCRIPTION
This program implements a basic calculator using two classes:

1. ArithmeticOperations
   Contains methods for addition, subtraction, multiplication, division, and modulus.

2. Calculator
   Handles user input and controls the menu driven execution of the program.

The program allows the user to repeatedly select operations until the exit option is chosen.

FEATURES
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Menu driven interface
- Division by zero error handling

FOLDER STRUCTURE
experiment-1/
    src/
        ArithmeticOperations.java
        Calculator.java
    README.txt

HOW TO COMPILE
javac src/*.java

HOW TO RUN
java src.Calculator

EXPECTED OUTPUT
- Program asks user to enter two numbers
- Displays menu with arithmetic operations
- Performs selected operation
- Continues until user selects Exit
